# Partikel

**Dipakai sejak:** Bab 1, bertambah di hampir setiap bab. Kolom Bab menunjukkan fungsi yang diperkenalkan; cocokkan dengan kemajuan kelas sebelum dipakai untuk recall.

**Bacaan khusus:** は dibaca **わ**, へ dibaca **え**, を dibaca **お**.

## Pasangan yang sering tertukar

| Pasangan | Pembeda | Contoh |
|---|---|---|
| **は vs が** | は = topik/kontras; が = subjek baru, subjek berupa kata tanya, dan predikat 好き・わかる・ある・欲しい | `だれが来ましたか` → `山田さんが来ました` |
| **に vs で (tempat)** | に = tempat “ada” / tujuan; で = tempat kegiatan | `部屋にいます` ↔ `部屋で勉強します` |
| **へ vs に (arah)** | Keduanya benar dengan 行きます・来ます・帰ります; へ menekankan arah, に tujuan | `日本へ／に行きます` |
| **と vs や** | と menyebut semuanya; や hanya contoh (sering + など) | `パンと卵` (hanya itu) ↔ `パンや卵など` |
| **から (awal) vs から (alasan)** | Nから = mulai dari; kalimatから = karena | `9時から` ↔ `暑いですから` |
| **まで vs までに** | まで = terus sampai; までに = batas waktu sekali tindakan | `5時まで働きます` ↔ `5時までに帰ります` |
| **で (alat) vs で (tempat)** | Lihat kata bendanya: benda alat vs tempat | `ペンで書きます` ↔ `教室で書きます` |

## Partikel + も

- が・を + も → **も saja**: `りんごも食べます` (bukan `りんごをも`).
- に・へ・で・と + も → **tetap ada**: `日本へも行きます`, `友達とも話します`.

## Jebakan

- `食堂に食べます` ✗ → `食堂で食べます` ✓ (kesalahan paling umum).
- `日本語をわかります` ✗ → `日本語がわかります` ✓.
- `だれは来ましたか` ✗ → `だれが来ましたか` ✓.
- `友達をあげます` ✗ (berarti “memberikan teman”) → `友達にあげます` ✓.
- Waktu relatif tanpa に: `明日に` ✗ → `明日` ✓ (lihat `03-hari-minggu-dan-waktu-relatif.md`).
