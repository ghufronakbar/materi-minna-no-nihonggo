## BAGIAN III: Melengkapi Kalimat (Pilihan Ganda)

Pilihlah opsi a, b, atau c yang paling tepat untuk melengkapi kalimat berikut!

21. A：すみません、　この　ペン　を　ください。  
    B：はい。　[ ... ]　{何|なに}　か　ありますか。  
    A：いいえ、　けっこう　です。  
    a. {他|ほか}に　　b. いつも　　c. よく

22. {母|はは}　の　{誕生日|たんじょうび}　です　から、　{私|わたし}　は　{母|はは}　に　{花|はな}　を　[ ... ]。

23. {私|わたし}　は　{友達|ともだち}　に　{手紙|てがみ}　を　[ ... ]。　うれしかった　です。

24. テレビ　が　[ ... ]　して　います。　{見|み}る　こと　が　{出来|でき}ません。
